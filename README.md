## 最便宜的 DMIT VPS 值不值得买？

如果你的需求是低成本运行：

* 个人博客；
* 小型 Web 服务；
* 测试环境；
* 学习 Linux；

入门套餐通常更合理。

例如 1 vCore、1GB 内存级别的 VPS 可以运行很多基础服务，但需要注意：

* 内存有限，不适合大量插件的网站；

低价 VPS 最大的问题通常不是“能不能运行”，而是“运行后是否稳定”。

一个 1GB VPS 可以启动网站，但如果同时运行数据库、缓存、监控和多个 Docker 服务，很容易出现资源不足。
